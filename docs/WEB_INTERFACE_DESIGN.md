# Web 界面改版说明

本次改版让首次使用者从页面结构识别用途、当前位置和下一步操作。采用《Don't Make Me Think》的自明导航思路，以及《写给大家看的设计书》的亲密性、对齐、重复和对比原则。实现入口为 `WebWorkspace/app/workspace-app.tsx`、`portfolio-dashboard.tsx` 和 `globals.css`。

## 阅读与操作顺序

每个页面按同一顺序回答四个问题：我在哪里（导航与面包屑）→ 我在看什么数据（数据来源开关与状态条）→ 现在该做什么（唯一的绿色实心按钮）→ 支撑判断的细节。

首页顺序为「今天先做这一件事 → 推荐事项与按钮 → 三步用法 → 进行中的项目 → 其他待处理 → 可展开的趋势」。项目页顺序为「项目名称与目标 → 标签 → 标签用途说明 → 下一步 → 当前阶段与任务」。

## 原则与实际改动

### Don't Make Me Think

| 原则 | 实现 |
| --- | --- |
| 页面自明，不需要猜 | 主导航每项附一句用途（如「复盘 · 对照证据做决定」）；首页用「看下一步 → 去 iPhone 练习 → 回来复盘」三步说明网页与 iPhone 的分工。 |
| 一屏只有一个明显的动作 | 首页仅「推荐」区有绿色实心按钮；项目卡片、调整计划等入口改为描边按钮，文字链接用下划线。渲染测试锁定首页只有一个主按钮。 |
| 知道自己在哪里 | 顶栏改为面包屑（学习项目 / 项目名），当前导航有左侧色条；保留返回链接与浏览器返回/前进。 |
| 先扫读，再阅读 | 统计卡片改为项目标题下的一行摘要；项目卡片用「当前阶段 / 完成标准 / 学习证据」三栏定义列表；统计范围切换从首屏移入「学习趋势」展开区。 |
| 去掉多余的话 | 删除无信息的头像、重复的「连接个人记录」胶囊；数据状态只在状态条出现一次，并附「如何连接个人记录」入口。 |
| 用户的语言 | 将残留的英文界面文字（`This week`、`Available`、`Over capacity`、`records found` 等）与 `30m` 缩写改为中文；每个项目标签下方用一句话说明用途。 |
| 说明实际能力 | 示例模式下「下一步」以正文展示并说明为何不可编辑，不再显示禁用的输入框和按钮；「调整计划」旁注明「先保存草稿，确认后才会生效」。 |

### 写给大家看的设计书（亲密性、对齐、重复、对比）

| 原则 | 实现 |
| --- | --- |
| 亲密性 | 项目卡片内「下一步」与对应按钮放在同一底色块；固定练习摘要并入「学习任务」卡片；项目页的下一步移到概览顶部。 |
| 对齐 | 所有页面共用 1180px 内容边界；首页推荐区、三步用法、项目列表左边缘一致；窄屏按阅读顺序单列。 |
| 重复 | 一套字体层级（宋体标题 + 苹方正文）、一种卡片、三种按钮（实心 / 描边 / 下划线文字）和同一组状态色贯穿所有页面。 |
| 对比 | 推荐区用渐变底色、大号宋体标题和黄色「推荐」标签；示例数据状态条为浅黄、个人记录为浅绿，状态色始终配有文字。 |

动效仅用于页面载入时按阅读顺序轻微上浮显示，`prefers-reduced-motion` 下关闭。项目列表搜索、云端版本检查、本地草稿与显式启用、草稿面板焦点循环与 Esc 关闭均保留。

课程名称、学习目标、证据描述等原始内容保留原语言；界面文字为中文，不构成完整多语言系统。

## 验证与验收边界

- Web 构建、`npm test`（67 项）与 lint 通过。渲染测试核对首屏层级顺序、唯一主按钮、三步用法、面包屑、中文可访问摘要，并断言界面不再出现英文统计文字；弱化文字色在卡片与状态条底色上对比度不低于 4.5:1。
- 无头 Chrome（1280 像素桌面、390 像素窄屏）：五个页面均无页面横向溢出、无控制台错误；桌面首屏和窄屏首屏均能看到推荐按钮；点击推荐按钮进入对应项目的复盘标签，面包屑与浏览器返回可用；搜索与清空、方向键切换标签、草稿面板 Esc 关闭并返回焦点、状态条进入「数据与同步」均通过。窄屏项目标签为有意的横向滚动，右缘有渐隐提示。
- 完整 `tsc --noEmit` 仍在 `worker/index.ts` 报 `Fetcher`、`D1Database` 全局类型缺失，与本次改动无关。
- 模拟窄屏不等于真机验收。尚未执行真实 CloudKit 读写、iPhone 同步、VoiceOver 或首次使用者可用性测试。字体依赖系统自带宋体，未安装时回退到衬线字体。

下一次验收建议：让首次接触产品的人独立找到下一步、打开一个项目、查看学习证据，并解释示例与个人记录的区别。记录发生犹豫的位置，再针对性调整。
