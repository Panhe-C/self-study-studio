# Express low frequency as cadence, not status

A Project worked on rarely is still Active, so `low-frequency` stops being a Project Status and becomes a matter of Practice Cadence, Planning Windows, and explicit Review Decisions. The old value already behaved like Active in the attention budget, Product Health, and migration checks, and mapping it to Paused would wrongly remove ongoing work from the Today Agenda; a Review that previously recommended reducing a Project to low frequency now recommends reducing its cadence or planned load instead.
