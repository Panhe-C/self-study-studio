# Keep a pre-commitment Project state

Active, Paused, Completed, and Abandoned describe Projects the learner has committed to, so an uncommitted Project keeps a separate `idea` state that carries no Goal, canonical Next Step, or Evidence Contract and never counts toward the attention budget or the Today Agenda. Folding `idea` into Active would push Projects with no executable commitment into Today and weaken the meaning of an Active Project, while dropping the state entirely would force the learner to finish committing before they are allowed to record the idea at all.
