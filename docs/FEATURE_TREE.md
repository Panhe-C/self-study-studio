## 状态口径

| 标记 | 含义 |
| --- | --- |
| ✅ 已实现 | 当前代码存在对应实现及入口；不等于已发布或本次测试通过 |
| ◐ 部分完成 | 已有基础能力，但未覆盖目标产品的完整范围 |
| ⬜ 未完成 | 尚缺对应功能或完整入口；未发现实现的判断仅限本次检查范围 |
| 🧪 待验收 | 已有实现，但真机、在线服务或用户体验验证尚缺证据 |
| — 暂不纳入 | 当前明确排除或延后，不计入核心功能缺口 |

父节点用于分类，状态标在叶节点。一个功能可同时「已实现」和「待验收」。

## 优先补齐的内容

下列顺序是基于本次盘点的建议，不是已确认的产品排期。

| 优先级 | 未完成内容 | 完成标准 |
| --- | --- | --- |
| P0 | 核心真机闭环与数据验收 | 记录计划 → 学习 → 确认 → 更正 → 调整的真机结果，并单独验证恢复、通知、附件和双端同步 |
| P1 | 明确 Milestone 的产品范围 | 决定沿用阶段目标，或补充独立多里程碑模型、编辑和状态；同步修订产品定义 |
| P1 | 可选计时和引导附件入口 | 同一引导闭环支持不计时；明确直接录音与链接是否必须在完成检查内提供 |
| P1 | 普通调整的实际操作范围 | 明确拆分 / 插入活动是否应一键完成，避免仅展示建议文字就视为操作已完成 |
| P2 | 当日覆盖持久化、教练对话历史 | 明确设备本地与跨端边界，再增加存储和恢复能力 |
| P2 | 拖拽排序、统一搜索、Web vNext 体验 | 按实际使用频率排期；Web 当前数据兼容不等于功能对等 |

对话持久化和统一搜索属于补充能力观察，不是 vNext 文档明确要求的发布阻断项。暂不纳入项不应计作待修复缺陷；AI 自动生效等项目还是当前产品明确禁止的行为。
